# 云之脑架构对齐 - 后端完善计划

## 一、云之脑架构核心要素

根据云之脑平台架构，核心包含以下系统：

```
┌─────────────────────────────────────────────────────────────┐
│                    云之脑平台架构                            │
├─────────────────────────────────────────────────────────────┤
│  感知系统  │  决策系统  │  知识中心  │  认知系统  │ 韧性保障 │
├─────────────────────────────────────────────────────────────┤
│  物联网    │  神经中枢  │  知识图谱  │  AI模型   │ 容错机制 │
│  传感器    │  研判决策  │  规则库   │  学习进化  │ 安全监控 │
└─────────────────────────────────────────────────────────────┘
```

## 二、当前后端与云之脑的对照

| 云之脑组件 | 当前实现 | 完善方向 |
|-----------|---------|---------|
| **感知系统** | ResearcherProfile输入 | ✅ 已实现基础感知 |
| **决策系统** | 5-Agent Orchestrator | ✅ 已实现基础决策流 |
| **知识中心** | 无 | ❌ **需要补充知识库** |
| **认知系统** | Learner Agent | ⚠️ 需要增强深度学习 |
| **韧性保障** | 无 | ❌ **需要容错/监控** |
| **神经网络** | FastAPI REST | ⚠️ 需要WebSocket实时通信 |

## 三、后端完善优先级 (按云之脑方案)

### P0 - 知识中心 (本周必须完成)

**当前问题**: 系统没有知识库，Agent的决策基于硬编码规则，缺乏真实药物知识。

**完善内容**:
1. **药物知识图谱** - 靶点-疾病-药物关系
2. **化合物数据库接口** - 集成ChEMBL/ZINC查询
3. **ADMET知识库** - 药物性质经验规则
4. **文献知识库** - 关键论文和实验数据

### P1 - 韧性保障系统 (本周完成)

**当前问题**: 没有错误恢复、没有服务监控、没有限流保护。

**完善内容**:
1. **全局异常处理** - 统一错误响应格式
2. **请求限流** - 防止前端刷接口
3. **服务健康检查** - /health 端点
4. **执行超时控制** - pipeline最长执行时间
5. **日志系统** - 结构化日志记录

### P2 - 认知系统增强 (下周完成)

**当前问题**: Learner只是简单记录反馈，没有真正的学习优化。

**完善内容**:
1. **反馈驱动的生成优化** - 根据历史反馈调整生成策略
2. **研究员画像学习** - 记住每个研究员的偏好
3. **靶点特异性模型** - 不同靶点用不同的评分权重
4. **A/B测试框架** - 对比不同策略效果

### P3 - 神经网络增强 (下周完成)

**当前问题**: 只有HTTP轮询，没有实时推送。

**完善内容**:
1. **WebSocket支持** - Agent状态实时推送
2. **SSE流式响应** - Pipeline执行进度实时返回
3. **异步任务队列** - 长时间任务后台执行

### P4 - FPGA深度对接 (下周完成)

**当前问题**: FPGA客户端是空壳，没有真实通信。

**完善内容**:
1. **TCP通信协议** - 与FPGA建立Socket连接
2. **分子指纹计算** - 发送SMILES，接收指纹
3. **Tanimoto批量计算** - 相似度矩阵计算
4. **性能对比** - FPGA vs CPU计算时间对比
